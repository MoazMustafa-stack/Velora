# Roadmap

1. **v0.1 bootstrap (current):** spatial Godot room, first-person controls,
   interaction, Rust Unix-socket core, ping/pong, safe demo launch request.
2. **Application model:** parse XDG desktop entries correctly, expose an app
   registry, and replace the demo catalog.
3. **Hyprland integration:** read workspaces and windows, then consume native
   Hyprland events instead of polling.
4. **System state:** native CPU, memory, and load telemetry.
5. **Optional integration:** only after validation, offer an additive Omarchy
   convenience binding or launcher entry.
