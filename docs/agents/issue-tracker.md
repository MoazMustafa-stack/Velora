# Issue tracker: GitHub

Issues and specs live in MoazMustafa-stack/Velora.
Use the gh CLI inside this repository.

Read: gh issue view <number>
List: gh issue list
Create: gh issue create --title "..." --body "..."
Comment: gh issue comment <number> --body "..."
Label: gh issue edit <number> --add-label "..."
Close: gh issue close <number>

PRs as a request surface: no.

Publish only owner-authorized material. Keep private Brain
notes and evidence out of public issue bodies.
